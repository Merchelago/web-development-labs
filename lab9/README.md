# Практическая работа 9 — Использование JavaScript для работы с DOM

**Студент:** Ананьев Александр Николаевич, ПГТУ
**Вариант 1:** Интерактивный список покупок

Клиентское приложение на чистом JavaScript (без фреймворков и серверной части). Чтобы запустить, откройте `index.html` в браузере.

## Возможности

- добавление товара: название, категория, количество;
- проверка ввода: пустое или слишком короткое название, количество вне диапазона 1–99, предупреждение о повторе названия;
- отметка «куплено», удаление товара с анимацией, удаление всех купленных, очистка списка с подтверждением;
- фильтры «Все / Купить / Куплено», фильтр по категории, сортировка;
- счётчики «Всего / Куплено / Осталось», прогресс-бар, всплывающие уведомления;
- сохранение списка в `localStorage` (дополнительно);
- адаптивная вёрстка для смартфонов.
