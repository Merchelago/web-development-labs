**Вариант:** 1 — Новостной портал

## Описание

Главная страница городского новостного портала «Наш Город» (Йошкар-Ола), свёрстанная по макету варианта 1:

- `header` — логотип и название портала, текущая дата, город, форма поиска;
- `nav` — главное меню рубрик;
- `main` — главная новость (`section` + `article`) и сетка последних новостей (`section` с шестью `article`);
- `aside` — блоки «Популярное», «Подписка на новости», «Погода в городе»;
- `footer` — описание проекта, навигация по разделам, контакты в `address`, служебные ссылки.

## Структура проекта

```text
lab5/

├── css/style.css     — внешняя таблица стилей
├── images/           — собственные SVG-иллюстрации и логотип
├── screenshots/      — скриншоты для отчёта
└── README.md
```

## Технологии

HTML5 (семантические элементы, `time`, `address`, `figure`, `dl`, формы с `label`), CSS3 (Grid, Flexbox,
пользовательские свойства, `::before`/`::after`, `:hover`/`:focus`/`:focus-within`, `transition`, `transform`,
`box-shadow`, `border-radius`, градиенты, медиазапрос `max-width: 768px`). JavaScript не используется.
