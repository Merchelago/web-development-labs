# Практическая работа №13. Прогрессивное web-приложение (PWA)

**Студент:** Ананьев Александр Николаевич, ПГТУ
**Вариант 1:** «Мобильный список покупок»

PWA «Мой список покупок» работает на телефоне, планшете и компьютере, устанавливается как отдельное приложение и продолжает работать без интернета.

## Возможности

- добавление товара (название, количество, единица измерения, категория) с проверкой ввода;
- отметка купленного, редактирование в диалоговом окне, удаление с отменой;
- фильтры «Все / Купить / Куплено», фильтр по категории, поиск;
- счётчик оставшихся товаров и индикатор прогресса;
- хранение списка в IndexedDB (если она недоступна — в localStorage);
- работа без сети, индикатор «Онлайн/Офлайн»;
- кнопка «Установить» (событие `beforeinstallprompt`), подсказка для iPhone;
- уведомление о новой версии и обновление по кнопке;
- светлая и тёмная тема, ярлык «Добавить товар» в меню значка приложения.

## Структура

```text
lab13/
├── index.html            — разметка приложения
├── offline.html          — запасная страница без сети
├── manifest.json         — Web App Manifest
├── service-worker.js     — кэширование и офлайн-режим
├── css/style.css         — адаптивные стили (mobile first, медиазапросы 480/600/960 px)
├── js/
│   ├── app.js            — состояние и обработчики событий
│   ├── db.js             — хранилище (IndexedDB / localStorage)
│   ├── ui.js             — отрисовка списка, уведомления
│   └── pwa.js            — регистрация Service Worker, установка, состояние сети
├── icons/                — иконки 72–512 px, maskable, apple-touch-icon
├── screens/              — снимки экрана для окна установки
└── tests/pwa_check.py    — автоматическая проверка PWA в Chrome
```

## Стратегии кэширования

| Запросы | Стратегия |
|---|---|
| HTML-страницы (навигация) | Network First, без сети — из кэша |
| Оболочка приложения: CSS, JS, иконки | Cache First (кэшируются при установке Service Worker) |
| Остальные файлы сайта | Stale While Revalidate |

При изменении файлов нужно увеличить `VERSION` в `service-worker.js`: браузер скачает новую версию, приложение покажет кнопку «Обновить», старые кэши удалятся.

## Запуск

Service Worker работает только в защищённом контексте — по HTTPS или на `localhost`.

```bash
cd lab13
python -m http.server 8013
```

Открыть http://localhost:8013/ в Chrome, Edge или другом браузере на основе Chromium.

## Установка

- **Android (Chrome):** меню ⋮ → «Установить приложение» (или кнопка «Установить» в шапке).
- **iPhone/iPad (Safari):** «Поделиться» → «На экран „Домой“».
- **Компьютер (Chrome/Edge):** значок установки в адресной строке или кнопка «Установить».

## Проверка

```bash
pip install playwright
python tests/pwa_check.py
```

Скрипт проверяет манифест и иконки, устанавливаемость, регистрацию Service Worker, содержимое кэша, сохранение данных и работу без сети.
