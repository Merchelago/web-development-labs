## Описание

Страница-путеводитель «ТурГид» с карточками туристических мест. Главная карточка («Место недели» — Амальфи)
и шесть компактных карточек (Интерлакен, Киото, мыс Рока, Санторини, Байкал, Киркьюфелл).

При наведении на карточку (или при фокусе с клавиатуры внутри неё):

- фотография плавно увеличивается (`transform: scale(1.08)`) внутри блока с `overflow: hidden` — размер карточки не меняется;
- поверх фото проявляется затемняющий слой — псевдоэлемент `.card__media::before` с `linear-gradient` из `rgba()`;
- выезжает текстовый overlay с дополнительными сведениями (`opacity` + `translateY`);
- карточка приподнимается, усиливается `box-shadow`, меняется цвет рамки, удлиняется декоративная линия под названием (`::after`), звезда рейтинга меняет цвет.

Кнопка «в избранное» сделана без JavaScript: скрытый `checkbox` + `:checked` + соседний комбинатор `+`.

## Технологии

HTML5, CSS3: пользовательские свойства (переменные), Grid/Flexbox, `transition`, `transform`, `box-shadow`,
`border-radius`, `linear-gradient`/`radial-gradient`, `rgba()`/`opacity`, `filter`, `mask` с SVG-иконками,
`::before`/`::after`, `:hover`, `:focus`, `:focus-visible`, `:focus-within`, `:checked`, `:invalid`,
счётчики CSS, `@keyframes`, медиазапросы.
