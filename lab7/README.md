## Описание

Адаптивная главная страница SaaS-сервиса TaskFlow для управления проектами:
шапка с навигацией и кнопкой «Войти», Hero-блок с изображением интерфейса на ноутбуке,
секция «Возможности» (3 карточки), информационный блок «Команда — главная ценность»,
тарифы и подвал с навигацией, соцсетями и копирайтом.

## Компоновка

| Блок | Desktop (> 768px) | Mobile (≤ 768px) |
|---|---|---|
| Header | Flexbox: логотип — меню — переключатель и «Войти» | Flexbox с переносом, меню сворачивается в бургер |
| Hero | Grid, 2 колонки (текст + ноутбук) | Grid, 1 колонка, кнопки во всю ширину |
| Возможности | Grid `repeat(3, minmax(0, 1fr))` | Grid `1fr`, карточка — иконка слева, текст справа |
| Команда | Grid, 2 колонки (фото + текст) | Grid, 1 колонка |
| Тарифы | Grid, 3 колонки, внутри карточки Flexbox | Grid, 1 колонка |
| Footer | Flexbox в строку | Flexbox в столбец |

- Контрольная граница адаптации — **768px** (`@media (max-width: 768px)`), дополнительно ≤ 1024px.
- **Переключатель «Авто / Desktop / Mobile»** в шапке: «Авто» — раскладка по ширине окна,
  «Desktop»/«Mobile» — принудительный выбор. Зелёная точка показывает применённую раскладку.
- Состояние (фильтр задач в интерфейсе на ноутбуке, отмеченные задачи, период оплаты тарифов,
  открытое меню) хранится в элементах формы и не сбрасывается при перестройке.
- `position`: `sticky` — шапка, `relative`/`absolute` — бейджи «Новое» и «Популярный».

## Проверка адаптивности

Проверено в Google Chrome на ширинах 1440, 1024, 769, 768 и 390px (эмуляция смартфона):
горизонтальной прокрутки нет, изображения не выходят за границы контейнеров и сохраняют пропорции.
