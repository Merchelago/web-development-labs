## Что реализовано

Рабочая страница TaskFlow собрана из функциональных React-компонентов:

| Компонент | Назначение |
|---|---|
| `Sidebar.jsx` | боковое меню с выделением активного раздела (Задачи, Календарь, Статистика, Метки, Настройки) |
| `SearchBar.jsx` | поиск по названию, описанию и меткам + фильтр «Все метки» |
| `TaskTabs.jsx` | вкладки «Все / Сегодня / В процессе / Завершенные / Просроченные» с динамическими счётчиками |
| `AddTaskButton.jsx` | кнопка, открывающая модальное окно `TaskModal.jsx` для добавления задачи |
| `Calendar.jsx` | календарь: листание месяцев, выбор даты (фильтр задач), отметки дней с задачами |
| `TopBar`, `StatsCards`, `TaskTable`/`TaskRow`, `TagProgress`, `SectionViews` | верхняя панель, карточки показателей, таблица задач, диаграмма «Прогресс по меткам», разделы меню |

Состояние хранится в `App.jsx` (`useState`) и передаётся вниз через props; дочерние компоненты сообщают о действиях через переданные функции. `useEffect` используется для загрузки данных (`public/data/tasks.json`), сохранения задач в `localStorage`, обновления текущего времени (просроченные задачи), заголовка вкладки браузера, автоскрытия уведомления, закрытия модального окна по Esc и синхронизации месяца календаря с выбранной датой.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5310
npm test         # тесты компонентов (Vitest + Testing Library)
npm run build    # production-сборка в dist/
```

Требуется Node.js 22.12+.
